# Issue #97: Remove 1Password

## Problem Statement
1Password (op) requires manual interaction and has been replaced with more convenient .env files for credential management. Need to remove all uses of 1Password from the toolbox and corresponding documentation.

## Solution
Complete removal of 1Password integration including:
- Authentication methods and configuration
- UI components and widgets
- Configuration files and documentation
- Testing and validation code

## Acceptance Criteria
- [ ] All 1Password authentication code removed
- [ ] All 1Password UI elements removed from widgets
- [ ] All 1Password configuration options removed
- [ ] All 1Password documentation removed
- [ ] Existing .env-based authentication still works
- [ ] Tests pass without 1Password dependencies

## Implementation Approach
Parallel implementation with 3 streams:
1. **Stream A**: Core code removal (backend)
2. **Stream B**: UI/Widget cleanup (frontend) 
3. **Stream C**: Configuration & documentation cleanup

## Files to Modify
### Core Code (Stream A)
- `clustrix/auth_methods.py`
- `clustrix/config.py`
- `clustrix/auth_manager.py`
- `clustrix/validation.py`
- `clustrix/secure_credentials.py`

### UI/Widgets (Stream B)
- `clustrix/modern_notebook_widget.py`
- `clustrix/enhanced_notebook_widget.py`

### Config/Docs (Stream C)
- `tests/test_config.yml`
- `ndoli_config.yml`
- `tensor01_config.yml`
- `docs/*.md`
- `CLAUDE.md`
- `scripts/README.md`
